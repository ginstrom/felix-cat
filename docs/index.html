About the manual

These are the Felix user manuals as last published on felix-cat.com (English: version 1.7.1.1). They describe the memory and glossary windows, the Office add-ins and scripting. A few details, such as installation, purchasing and update checks, refer to the original commercial releases and no longer apply: Felix is now free, and new versions are published on GitHub.
