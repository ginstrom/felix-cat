4.3.3. Glossary Matches¶

Glossary matches appear in the glossary window.

The ordering of glossary matches is as follows (highest to lowest priority):

  1. Reference count (How many times you use a glossary term. Frequently used terms “bubble up” to the top)
  2. Reliability score
  3. Validated status
  4. Length of gloss source/translation (usually, longer matches are more useful)
  5. Date created (newest to oldest)
