5. Using Felix from Word

For a quick introduction to using Felix from Microsoft® Word, see the Quick Start Tutorial for MS Word.

The Microsoft Word interface has two modes: Translation mode and Review mode. Additionally, a “classic interface” is still available to those who prefer the interface from version 1.2 and earlier.

5.1 Getting Started

In order to use Felix from Microsoft Word, you must select the Microsoft Interface component during installation. See 2.2 Installation for details.

The Felix interface for Microsoft Word consists of a menu, a toolbar, and keyboard shortcuts. See the following sections for details.

When Microsoft Word first launches after installing Felix, the interface is in Translation Mode (see 5.2 Translation Mode) with the new interface. If you would like to switch back to the class interface, you must set this in the Preferences.
