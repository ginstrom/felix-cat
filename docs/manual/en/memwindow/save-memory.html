4.2.8. Save the Memory¶

To save the current memory, select File ‣ Save from the menu. Alternately, use the Ctrl+S shortcut.

To save all currently loaded memories, select File ‣ Save All.

If you are saving the memory for the first time, the Save Memory dialog will prompt you to select a location and name for the memory file. You can also select a new location and/or name for an existing memory by selecting File ‣ Save As... from the menu.

You can save memories in the following formats:

  • Felix .ftm format (the default)
  • TMX format
  • Trados Text format
  • As an Excel file

Choose the appropriate file type from the Save Memory dialog box.
