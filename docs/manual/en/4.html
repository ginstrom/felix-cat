4. The Felix Menus

This section describes the Felix menus, what they do, and their keyboard shortcuts, if any.

4.1 The Memory Window Menus

This section describes the menus for the main Felix window.

4.1.1 The File Menu

New  
Glossary Creates a new Glossary window. See 3.2.12 Open a New Glossary Window for details.
Memory Ctrl + N Creates a new memory. See 3.2.10 Clear the Memory for details.
Open Ctrl + 0 Opens an existing memory. See 3.2.8 Open a Memory for details.
Connect...
Connect to a memory on your network. See 3.2.13 Connect to a Memory on the Server for details.
Save
Ctrl + S
Saves the current memory. See 3.2.9 Save the Memory for details.
Save As... Saves the current memory with a new name. See 3.2.7 Save the Memory for details.
Save All Saves all currently loaded memories. See 3.2.7 Save the Memory for details.
Recent Files
A list of recently used memory files.
Exit
Exits the application.

Back to Contents | Top

4.1.2 The Edit Menu

Find  
Search Memory Ctrl+F Searches the memory. See 3.2.2 Search the Memory for details.
Concordance Finds concordances in the memory. See 3.2.2 Search the Memory for details.
Replace Ctrl + H Calls up the Replace Text dialog. Only enabled in Edit Mode. See 3.4.3 Search and Replace for details.
Copy
Ctrl + C
Copies the current selection into the clipboard.
Cut Ctrl + X Deletes the current selection, and places it in the clipboard. Only enabled in Edit Mode.
Paste Ctrl + V Pastes the clipboard contents at the current selection point. Only enabled in Edit Mode.
Edit Entry
Edits the current entry (entry number 0 if a list is being displayed). See 3.2.1 Add an Entry for details.
Delete Entry Ctrl + D Deletes the current entry (entry number 0 if a list is being displayed). See 3.2.4 Delete an Entry for details.
Add Entry Calls up the Add Entry dialog. See 3.2.1 Add an Entry for details.

Back to Contents | Top

4.1.3 The View Menu

Toolbar    Shows or hides the toolbar.
Status Bar   Shows or hides the status bar.
Edit Mode Ctrl + E Toggles between Edit Mode and Browse Mode. See 3.4 Edit Mode for details.
Current View
Match View Switch to the translation match view.
Search View Switch to the search/concordance view
Compact View
Show the Memory window in compact mode. The glossary window is hidden, and the Memory window appears as a floating toolbar.

Back to Contents | Top

4.1.4 The Format Menu

Font... Calls up the Font dialog, where you can set the face, bold/italic, size, underline, and color of the current text selection. Only enabled in Edit Mode. See 3.4.2 Editing and Formatting Text for details.
Background Color... Select a background color for the window. This setting has no effect on the actual memory, but is useful if you are translating white or other light-colored text.

Back to Contents | Top

4.1.5 The Tools Menu

Preferences...   Calls up the User Preferences dialog. See 3.2.11 Set User Preferences for details. 
UI to Japanese/English Ctrl + L Converts the UI to Japanese or English, depending on the current UI language.
Memory Manager... Calls up the Memory Manager dialog. See 3.2.12 Manage Your Memories for details.

Back to Contents | Top

4.1.6 The Help Menu

About Felix... View version and copyright information for Felix.
View Help F1 Displays this help file in a separate browser window.
FAQ... View the Felix FAQ.
Register...
Register your copy of Felix.

4.2 The Glossary Window Menus

This section describes the menu items for the glossary windows.

4.2.1 The File Menu

New Ctrl + N Clears the current glossary, and creates a new one.
Open Ctrl + 0 Opens an existing memory. See 3.3.2 Open a Glossary for details.
Save Ctrl + S Saves the current glossary.
Save As... Saves the current glossary with a new name.
Save All Saves all current glossaries.
Recent Files
A list of recently used glossary files.
Close
Closes the Glossary window.

Back to Contents | Top

4.2.2 The Edit Menu

Copy Ctrl + C Copies the current selection into the clipboard.
Cut Ctrl + X Deletes the current selection, and places it in the clipboard. Only enabled in Edit Mode.
Paste Ctrl + V Pastes the clipboard contents at the current selection point. Only enabled in Edit Mode.
Find
Ctrl + F
In Edit Mode, calls up the Find Text dialog. In Browse Mode, calls up the Find Glossary Entry dialog.
Replace Ctrl + H Calls up the Replace Text dialog. Only enabled in Edit Mode.
Add Glossary Entry
Calls up the Add Glossary Entry dialog. See 3.3.5 Add an Entry to the Glossaryfor details.

Edit Mode Ctrl + E Toggles between Edit Mode and Browse Mode. See 3.4 Edit Mode for details.
Status Bar Shows or hides the status bar.
Current View
Match View Switch to the glossary match view.
Search View Switch to the search/concordance view

4.2.4 The Format Menu

Font... Calls up the Font dialog, where you can set the face, bold/italic, size, underline, and color of the current text selection. Only enabled in Edit Mode. See 3.4.2 Editing and Formatting Text for details.
Background Color... Select a background color for the window. This setting has no effect on the actual glossary, but is useful if your are translating white or other light-colored text.
