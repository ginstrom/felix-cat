3.2.9 Change the UI Language

You can toggle the user interface dynamically between English and Japanese. To do so, from the Tools menu, select UI to Japanese. Note that this menu item is context-sensitive: If the UI is Japanese, the menu item will be UI to English.

Alternately, you can use the Ctrl+L keyboard shortcut.

The helpfile language version corresponding to the current UI language is displayed when you select Help > View Help (or press F1 when the Memory window is in focus).
