3.2.8 Create a New Memory

Felix allows you to have any number of memories open at one time. You can either load memories from files, connect to memories over the local network on a Memory Serves server, or create a new memory. This section describes how to create a new memory.

From the File menu, select New > New Memory.

Alternately, you can use the Ctrl+N keyboard shortcut, or the Toolbar command.

A new memory is created and set as the active memory.
