3.2.13 Connect to a Memory on the Server

In order to use this feature, you’ll need to install Memory Serves, a free program to share Felix memories over a local network.

Once you have Memory Serves running, copy the connection string for the desired memory, and then from Felix, select File >> Connect….

The Connection Dialog appears. Copy in the connection string, and click OK.

This will connect you to the Felix memory on the Memory Serves server. The memory will behave just like an ordinary Felix memory, except you won’t need to save it (the server will take care of that).
