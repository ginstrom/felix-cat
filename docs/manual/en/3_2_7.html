3.2.7 Save the Memory

To save the current memory, from the File menu, select Save. Alternately, use the Ctrl+S shortcut.

If you are saving the memory for the first time, the Save Memory dialog will prompt you to select a location and name for the memory file. You can also select a new location and/or name for an existing memory by selecting Save As… from the File menu.

To save all currently loaded memories, select Save All.

You can save memories in Felix xml format (the default), or in TMX format, Trados Text format, or as an Excel file. Choose the appropriate file type from the Save Memory dialog box.
