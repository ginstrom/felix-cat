2. Getting Started¶

This section describes how to download, install, and uninstall Felix.

2.1. Downloading¶

Download the Felix_Setup_<version>.exe asset from the latest release on GitHub.

2.2. Installation¶

Close Felix, Word, Excel and PowerPoint. Run the downloaded installer and follow the prompts. Windows may ask for administrator approval.

If you are upgrading from Felix 2.0, back up %LOCALAPPDATA%\Felix before uninstalling 2.0. The 2.0 uninstaller removes that settings and templates folder. Install Felix 3 after removing 2.0 so Office starts the current version.

2.2.1. Choosing Components¶

On Select Components, choose which optional add-ins to install for 64-bit Word, Excel and PowerPoint. The installer also sets up Felix and the required Visual C++ runtimes.

After setup, open an Office document and choose the Add-ins tab to find the Felix menu and toolbar. See Troubleshooting if they do not appear.

2.2.2. Licensing¶

Felix 3 is open source. It runs without a license key or a trial record limit.

2.3. Uninstallation¶

  1. Close Felix and any running Office applications.
  2. In Windows 11, open Settings → Apps → Installed apps. In Windows 10, open Settings → Apps → Apps & features.
  3. Find Felix, choose Uninstall, and follow the prompts.

The Felix 3 uninstaller leaves your saved memories, glossaries and settings in place.
