3.3.6 Save the Glossary

To save your glossary, from the File menu, select Save.

The Save Glossary dialog box appears. Select the name and location of your glossary, and the format you would like to save it in. The following formats are available:

  1. Felix XML glossary format (default)
  2. Trados Multiterm format (version 5.0 or 6.0)
  3. As an Excel file (great for sharing glossaries with others)

If you save the glossary as a Multiterm file, a dialog box will appear asking for the source and translation languages. Select the appropriate languages and click OK to save the glossary.
