3.3.5 グロサリにエントリを追加する

翻訳メモリ ウィンドウからグロサリ ウィンドウに対してグロサリ エントリを追加するほかに、グロサリ ウィンドウのメニューを使用してエントリを直接追加することができます。グロサリ ウィンドウの [編集(E)] メニューから [グロサリ エントリの追加(A)] を選択してください。[グロサリ エントリの追加] ダイアログ ボックスが表示されます。 このダイアログ ボックスの使用方法は、翻訳エントリをメモリに追加するダイアログと同じです。詳細については、「3.2.1 翻訳エントリを追加する 」を参照してください。

また、マイクロソフト エクセルから用語集の取り込みもできます。詳細について、 6.8 グロサリ エントリを登録するを参照してください。
