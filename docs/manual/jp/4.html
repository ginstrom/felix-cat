Felix マニュアル

4. Felix メニュー

ここでは、Ｆｅｌｉｘのメニュー、メニューを選択したときの動作、およびショートカット キーの有為について説明します。

4.1 翻訳メモリ ウィンドウのメニュー

ここでは、Felix 翻訳メモリ ウィンドウのメニューを説明します。

4.1.1 [ファイル] メニュー

新規(N)  
グロサリの作成(G) 新しいグロサリ ウィンドウを開きます。詳細は3.2.12 新しいグロサリ ウィンドウを開くを参照。
メモリの作成(M) Ctrl + N 新しい翻訳メモリを作成します。詳細は3.2.10 翻訳メモリをクリアするを参照。
開く(O) Ctrl + 0 既存のグロサリを開きます。詳細は3.2.6 翻訳メモリを開を参照。
接続...
ネットワーク（LAN）を通じてFelixメモリに接続する。詳細は3.2.13 翻訳メモリをクリアするを参照。
保存(S)
Ctrl + S
現在のグロサリを同じ名前で保存します。詳細は3.2.7 翻訳メモリを保存するを参照。
名前を付けて保存...(A) 現在の翻訳メモリを新しい名前で保存します。詳細は3.2.7 翻訳メモリを保存するを参照。
すべてを保存(L) 現在ロードしているすべての翻訳メモリおよびグロサリ メモリを上書き保存します。詳細は3.2.7 翻訳メモリを保存するを参照。
最近使ったファイル
最近使用した翻訳メモリ ファイルの一覧が表示されます。
Felixの終了(E)
Felix アプリケーションを終了します。

4.1.2 [編集] メニュー

検索(F)  
メモリの検索(M) Ctrl+F メモリを検索します。詳細は3.2.2 翻訳メモリを検索するを参照。
コンコーダンス(一致)検索(C) メモリでコンコーダンス(一致)を検索を行います。詳細は3.2.2 翻訳メモリを検索するを参照。
置換(R) Ctrl + H [置換] ダイアログを開きます。この機能は編集モードのみで使用できます。詳細は3.4.3 検索と置換を参照。
コピー(C)
Ctrl + C
選択範囲をクリップボードにコピーします。
切り取り(U) Ctrl + X 現在の選択範囲を削除して、その内容をクリップボードに転送します。この機能は編集モードのみで使用できます。
貼り付け(P) Ctrl + V クリップボードの内容を現在選択している位置に貼り付けます。この機能は編集モードのみで使用できます。
エントリの編集(E)
現在のエントリ（複数のエントリが表示されている場合はエントリ番号0）を編集します。詳細は 3.2.1 翻訳エントリを追加するを参照。
エントリの削除(D ) Ctrl + D 現在のエントリ（複数のエントリが表示されている場合はエントリ番号0）を削除します。詳細は 3.2.4 翻訳エントリを削除する を参照。
エントリの追加(A ) エントリを追加するためのダイアログを開きます。詳細は 3.2.1 翻訳エントリを追加するを参照。

目次に戻る | 先頭に戻る

4.1.3 [表示] メニュー

ツール バー(T)    ツールバーの表示/非表示を切り替えます。
ステータス バー(S )   ステータス バーの表示/非表示を切り替えます。
編集モード(E) Ctrl + E 編集モードと表示（ブラウズ）モードを交互に切り替えます。詳細については3.4 編集モードを参照してください。
現在のビュー(V)
マッチビュー(M) 原文/訳文の一致表示画面に切り替えます。
検索ビュー(S) 検索結果/コンコーダンス（一致）検索結果の画面に切り替えます。
小型表示(C)
翻訳メモリウィンドウを小さく表示します。グロサリウィンドウは非表示となり（ただし、登録されている用語が検索された場合は表示）、翻訳メモリウィンドウはフローティングツールバーとして表示されます。

目次に戻る | 先頭に戻る

4.1.4 [書式] メニュー

フォント...(F) [フォント] ダイアログを開きます。 このダイアログでは、現在選択しているテキストについて、フォントの種類、スタイル（太字、斜体）、サイズ、文字飾り（下線、色）を設定することができます。この機能は編集モードのみで使用できます。詳細は3.4.2 テキストの編集と書式設定を参照。
背景色の設定...(B) ウィンドウの背景色を設定します。この設定は実際の翻訳メモリには影響を与えませんが、白色や淡色のテキストを編集するときなどに便利です。

目次に戻る | 先頭に戻る

4.1.5 [ツール] メニュー

プロパティ...(P) [ユーザ設定] ダイアログが表示されます。詳細については「3.2.11 ユーザ設定を定義する 」を参照してください。
UI to Japanese/English Ctrl + L ユーザー インターフェイス（UI）の現在の表示言語に応じて、UI の表示言語を英語または日本語に切り替えます。
メモリ管理(M)... 翻訳メモリを管理するための [メモリ管理] ダイアログを開きます。詳細は3.2.12 翻訳メモリを管理するを参照。

目次に戻る | 先頭に戻る

4.1.6 [ヘルプ] メニュー

Felixのバージョン情報...(A) Felix のバージョン情報と著作権情報を表示します。
ヘルプの表示(H) F1 このヘルプ ファイルを別のブラウザ ウィンドウに表示します。
FAQ(よくある質問)の表示... Felix に関するFAQ（よくある質問）を表示します。
ソフトの登録(R)...
Felixの永久解除キーを登録します。

閉じる(C)
グロサリ ウィンドウを閉じます。
