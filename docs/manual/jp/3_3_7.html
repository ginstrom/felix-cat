3.3.7 グロサリを管理する

翻訳メモリは一度にいくつでも開くことができますが、コンピュータの物理メモリとディクススペースによっては制限されます。さまざまなグロサリを管理するには、[グロサリマネージャー] ダイアログ ボックスを使用します。

グロサリの管理方法はメモリの管理方法と同じです。 詳細については、「3.2.12 翻訳メモリを管理する 」を参照してください。
