3.3.3 グロサリ エントリを編集する

メモリ ウィンドウの場合と同様に、グロサリ エントリを編集する最も簡単な方法は、編集モードに入って、画面上でエントリを編集することです。詳細については「3.4 編集モード 」を参照してください。

[グロサリ エントリの編集] ダイアログを使用してグロサリ エントリを編集することもできます。グロサリ エントリの編集方法は、単一のエントリが表示されているか、複数のエントリが表示されているかに応じて若干異なります。

単一のグロサリ エントリが表示されたグロサリ ウィンドウ（シングル ビュー）

この状態のグロサリ エントリを削除するには、[削除] をクリックします。

複数のグロサリ エントリが表示されたグロサリ ウィンドウ（リスト ビュー）

この状態のグロサリ エントリを編集する場合は、編集するエントリの左側のボックス内にある [E] をクリックします。

[グロサリ エントリの編集] ダイアログ ボックスが表示されます。

このダイアログボックスの機能は、翻訳メモリの編集に使用する [エントリの編集] ダイアログボックスと同じです。詳細については、[3.2.3 翻訳エントリを編集する ] を参照してください。
