6. Word で Felix を使用する¶

Felixチュートリアル：MSワードで使う では、FelixをMicrosoft Wordからの利用を簡単に説明します。

Microsoft Word の内部からインターフェイスを通じて Felix の機能を使用するには、インストール時に Microsoft Interface コンポーネントを選択する必要があります。詳しくは インストール を参照してください。

Felix の Microsoft Word 用インターフェイスとは、メニュー、ツールバー、およびキーボード ショートカットのことをいいます。詳しく後述のセクションを参照してください。

Wordインターフェイスでは、 翻訳モード と 校正モード という、二つのモードがあります。Felixをインストールしてから初めてWordを起動するとき、翻訳モードで起動します。
