3.3.4 グロサリ エントリを削除する

グロサリ エントリを編集する場合と同様に、グロサリ エントリの削除方法は、単一のエントリが表示されているか、複数のエントリが表示されているかに応じて若干異なります。

単一のグロサリ エントリが表示されたグロサリ ウィンドウ（シングル ビュー）

この状態のグロサリ エントリを削除するには、[削除] をクリックします。

複数のグロサリ エントリが表示されたグロサリ ウィンドウ（リスト ビュー）

この状態のグロサリ エントリを削除する場合は、削除するエントリの左側のボックス内にある [D] をクリックします。

注記

グロサリ エントリを削除しようとすると、確認を求めるダイアログ「このエントリを削除しますか？」が表示されます。エントリを完全に削除してよい場合は、[はい] をクリックします。翻訳エントリの削除を中止する場合は、[いいえ]をクリックします。一度削除したエントリは復元できませんので、十分注意してください。
